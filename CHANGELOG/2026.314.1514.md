# 2026.314.1514 — refactor(schema): derive the appium word sets from vocabulary tables

## Summary

Convert the two inline `|` word unions in `candy/plugin-appium/schema/appium.cue` to the
§10.1 S3 vocabulary-table idiom, so each closed set of words has ONE home and the enum an
author meets is `or()` of that table's derived word list:

```
_method  (48 words) -> _methodWord -> #AppiumInput.method
_action  ( 3 words) -> _actionWord -> #AppiumInput.action
```

That is the 2 `union` rows `design/dpat-baseline.tsv` records for
`plugin-appium/candy/plugin-appium/schema/appium.cue` — two disjunctions, one row each,
both pure word lists. No other row names this repo, so this PR retires the whole of its
census debt (2 of 2; 0 left).

**How this repo was picked.** It is the first unit of this batch, from the
entirely-word-list set re-derived from `git show origin/main:design/dpat-baseline.tsv` —
strip a trailing `@go(...)` and enclosing parens, drop an empty trailing alternative, then
ask whether every alternative is a quoted string. Ranked by row count with ties broken by
word count, this batch's three are `plugin-appium` (2 rows, 51 words), `plugin-vm` (2 rows,
30 words) and `plugin-cdp` (2 rows, 25 words); `plugin-appium` is first.

**The one judgement this repo needs: two different vocabularies sit on the same def.**
`#AppiumInput.method` is the W3C method catalog; `#AppiumInput.action` is the DETACHED
recorder's bracket (`start|stop|status`, session_method.go's `switch in.Action`). They are
two tables because they are two sets that only share a def — merged, an
`action: "click"` would validate here and then fall through the switch to
`session requires action` at dispatch. `TestSessionActionsAreSchemaActions` pins each set
against its OWN router, in both directions.

Note the method table carries 48 rows, not the 47 a hand transcription of the union
produces: the assertion in the sweep script that the extracted set is exactly 48 words
caught my own miscount before any file was written.

No word moves: the accepted sets are IDENTICAL before and after — 48 methods, 3 actions —
read from the compiled CUE on both sides (370-case differential below). The umbrella leg —
the pin plus the emission-diffed census — is the lead's, by emission; this PR touches
neither `design/dpat-baseline.tsv` nor the umbrella.

opencharly/plugin-spice#15 (the two-vocabulary judgement call),
opencharly/plugin-desktop-kind#4 (no params projection), plus
